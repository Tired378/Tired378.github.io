# Tired378.github.io

Personal portfolio website hosted on GitHub Pages.

## Features
- Professional bio and introduction
- Skills and expertise showcase
- Links to personal app downloads from releases repository
- Contact information and GitHub profile
- Responsive design for all devices

## Visit
The portfolio is live at: https://tired378.github.io

## Local Development
To view locally, simply open `index.html` in a web browser or run a local server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`
